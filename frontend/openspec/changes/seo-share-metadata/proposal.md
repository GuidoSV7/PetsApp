# Proposal: SEO + share cards (WhatsApp / Facebook)

## Problem

PetsApp has thin root metadata (no OG image, weak Twitter cards). Shared links
look empty in WhatsApp and Facebook.

## Solution

Copy Elena Pos (`pos-new-style`) share pattern: dedicated share metadata helper,
Open Graph + Twitter cards, absolute site URL, default share image, robots/sitemap
wired to the public origin.

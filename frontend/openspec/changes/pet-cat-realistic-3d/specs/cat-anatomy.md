# Spec: cat anatomy

- Anatomy exposes parts with ids covering body, head, both ears, both eyes,
  both pupils, nose, at least one whisker, at least two tail segments, and
  four paws.
- Material roles are only: primary, secondary, accent, eye, pupil, whisker.
- Sitting feline layout: head Y above body Y; body depth (Z scale/extent)
  greater than a sphere toy (body uses elongated scale or capsule).
- `Cat3DModel` still accepts coat colors and interaction callbacks (smoke via
  existing stage tests that mock the viewer).
